# Shopping Cart Implementation

A Laravel application that allows administrators to list products for sale to customers. This project uses php and node.js backend with a Tailwind CSS with vite and Bootstrap front-end.

## Tech Stack

| Layer         | Technology    |
| ------------- | ------------- |
| Framework     | Laravel       |
| Database      | PostgreSQL    |
| Frontend      | Bootstrap, Tailwind CSS with Vite   |


## Views
Excluding views provided by Laraval (e.g. /auth, /profile)

| Folder        | Name    | Purpose |
| ------------- | --------| ------- |
| /admin         |dashboard| Dashboard where admin can create/update/delete product|
| /admin/products         |products-create| Form to create new product |
| /admin/products         |products| View individual product |
| /customer         |home| Customer homepage |
| /customer/cart         |index| Cart page |
| /customer/cart/partials        |table| Cart table |
| /customer/orders        |index| View all orders |
| /customer/orders        |show| View individual order |
| /layouts        |admin| Admin layout |
| /layouts        |app| App layout |
| /layouts        |customer| Customer layout |
| /layouts        |guest| Guest layout (unused) |
| /layouts        |navigation| Navigation layout (used for admin dashboard)|
| /pages       || |
| /partials       |customer-footer| Footer used in customer layout|
| /partials       |customer-nav| Navigation bar used in customer layout|
| /partials       |customer-nav| Navigation bar used in customer layout|
| /products       |details| View individual product details|
| /products       |edit| Edit product page|
| /products       |index| View all products|
| /products/partials      |grid| Grid for listing all products|
